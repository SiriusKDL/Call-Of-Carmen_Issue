# 卡门的呼唤 — 问题反馈

本仓库用于收集 Minecraft 模组 **卡门的呼唤** 的错误反馈与功能建议，不包含源码。

提交前请先搜索已有 Issue，避免重复反馈。

反馈错误时，请提供：
- 模组、Minecraft 和 NeoForge 版本
- 复现步骤、预期表现与实际结果
- 相关日志或截图
- 单人游戏或多人联机
- 错误报告

提出功能建议时，请说明你的想法及其对游戏体验的帮助。

欢迎使用中文或英文反馈。

模组下载地址:https://www.curseforge.com/minecraft/mc-mods/the-call-of-carmen

# Call of Carmen — Issue Tracker

This repository collects bug reports and feature suggestions for the **Call of Carmen** Minecraft mod. It does not contain source code.

Please search existing issues before opening a new one.

For bug reports, please include:
- Mod, Minecraft, and NeoForge versions
- Steps to reproduce, expected behavior, and actual results
- Relevant logs or screenshots
- Whether you are playing in singleplayer or multiplayer
- Crash Report

For feature suggestions, describe your idea and how it would improve the experience.

Feedback in English or Chinese is welcome.

Link to curseforge:https://www.curseforge.com/minecraft/mc-mods/the-call-of-carmen
